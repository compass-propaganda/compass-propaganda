# 주보 발행

주보는 새로 승인한 권장과 주요 변경을 전합니다. 요약에서도 원문의 적용 조건과 Pn을 유지하고, 자세한 근거는 원문으로 연결합니다.

## 발행 절차

`TEMPLATE.md`를 복사하여 `001-title.md`처럼 고유한 번호로 작성합니다. `status: draft`인 글은 사이트와 RSS에서 제외합니다.

발행할 때 `status`를 `published`로 바꾸고 `published_at`에 시간대가 포함된 발행 시각을 기록합니다. 예: `"2026-09-06T12:00:00+09:00"`. 제목은 본문의 첫 `#` 제목에서, 목록과 메일에 표시할 요지는 `summary`에서 읽습니다. 미래 시각의 발행은 빌드 오류입니다.

사이트 빌드가 주보 목록·본문과 루트의 `feed.xml`을 생성합니다. RSS에는 발행한 주보의 제목·요지·원문 링크를 싣습니다. 권장이나 정경을 수정하는 것만으로는 새 메일이 발송되지 않습니다.

주보 번호는 RSS 항목의 고유 식별자입니다. 발행 후 번호를 재사용하거나 기존 글의 발행 시각을 편집 시각으로 바꾸지 않습니다. 수정이 새 알림을 필요로 한다면 별도 주보로 발행합니다. 이미 전달된 이메일은 원문 수정으로 회수되지 않습니다.
